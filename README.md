# img-diff

离线可用的本地图片对比工具——单文件 HTML，零依赖。下载 `index.html` 后断网双击即可使用，图片不上传、无任何网络请求。

## 功能

- **仅两张图参与对比**：选满两张进入对比界面，随时可点击 A/B 槽位文件名替换任一张，替换后重新自动对齐
- **差异标注**：差异检测基于原始彩色像素逐通道比对（不是灰度比对）；界面将两图渲染为灰度，差异像素以红点标注，在灰度底上更醒目
- **差异阈值可调**：0–120，默认 20，拖动实时重算
- **三种视图**：重叠（可切 A / B / 半透明混合）/ 左右并排 / 上下并排；并排视图同步缩放平移，红点各标各的
- **缩放平移**：双指捏合缩放 + 单指拖拽平移；桌面为滚轮缩放 + 拖拽
- **图层选择**：同步 / 单独操作图A / 单独操作图B——选中单图时只变换该图，另一图保持不动
- **默认自动对齐**：两图拉伸至完全相同的矩形网格（纵横比不同会轻微变形），像素网格严格一一对应
- **手动对齐模式**：缩放后主体对不齐时使用——逐张放大到像素级（可见可点选的正方形像素格，方向键 ±1px 微调，Shift+方向键 ±10px），每张图标定 2 个对应锚点，确认后自动解算**平移 + 缩放 + 旋转**相似变换，使两对锚点精确重合，差异在对齐后的坐标系重新计算

## 使用

1. 下载 `index.html`，浏览器打开
2. 选择两张图片（或拖入页面）
3. 拖动"差异阈值"滑块调整灵敏度
4. 若自动对齐后主体错位：点"手动对齐" → 在图A、图B上分别点选两个对应锚点（选主体的固定特征点，如同一个角、同一颗螺丝）→ 放大到像素格可精确点选 → 确认对齐

## 技术说明

- 手动对齐以图A的分辨率为比较网格，图B经相似变换重采样到该网格；图B未覆盖或透明区域不参与比较
- 超大图片自动限制比较网格总像素（约 1500 万）以保证浏览器 canvas 兼容性
- 支持浏览器可解码的格式（PNG / JPEG / WebP / GIF 等）
- 灰度系数 0.299R + 0.587G + 0.114B；放大超过 3 倍自动切换最近邻采样，像素方块清晰可见
